# Release Docs

이 폴더는 릴리스 정책, 배포 기준, 공개 문서 분류 기준과 관련된 문서를 저장합니다.

## 현재 공개 기준 버전

- Uni-HWP 외피/API: `0.1.0`
- RHWP 엔진: `v0.8.6`
- 전체 Uni-HWP 식별 버전: `8.6.0`

통합 버전은 RHWP 엔진 버전의 숫자 식별값에 `×10`을 적용합니다. 따라서 RHWP `0.8.6`의 Uni-HWP 통합 버전은 `8.6.0`입니다.
