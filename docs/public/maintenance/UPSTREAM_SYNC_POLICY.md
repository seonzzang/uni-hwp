# Upstream Sync Policy

`UNI-HWP`는 `edwardkim/rhwp`를 업스트림으로 사용하지만, 단순 미러는 아니다.  
이 저장소는 `RHWP`의 공통 엔진 위에 제품화 레이어를 얹은 파생 프로젝트이므로, 자동 동기화는 경계를 지켜야 한다.

## 자동 동기화 원칙

- 업스트림은 `edwardkim/rhwp`로 고정한다.
- 공통 엔진과 공용 자산만 자동으로 반영한다.
- `UNI-HWP` 전용 레이어는 자동 덮어쓰지 않는다.
- 변경은 먼저 PR로 만들고, 저장소 설정이 허용하면 auto-merge 한다.

## 제외 대상

- `apps/`
- `site/`
- `docs/public/`
- 릴리즈 및 배포 workflow
- 제품 브랜딩과 소개 문구

## 동기화 대상 예시

- Rust/WASM 엔진 핵심
- 공통 렌더링/파서/테스트/샘플
- 공용 폰트 및 웹 엔진 자산
- `npm` 패키지의 엔진 공통부

## 실패 시 처리

- upstream fetch 실패 시 즉시 중단한다.
- 변경 대상이 비어 있으면 PR을 만들지 않는다.
- PR 생성 후 auto-merge가 막히면 저장소 설정을 점검한다.
