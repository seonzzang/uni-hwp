# Legacy TypeScript Definitions

`typescript/` 폴더는 과거의 타입 정의 보관 영역입니다.

현재 참조해야 하는 타입 정의의 기준 위치는 `pkg/rhwp.d.ts` 입니다.

이 폴더는 다음 목적을 위해 임시로 유지됩니다.

- 과거 `typescript/uni-hwp.d.ts` 배치의 이관 흔적 보관
- 외부 문서나 오래된 링크를 점검하기 위한 레거시 참조 지점

삭제 전 체크:

1. `pkg/rhwp.d.ts` 기준으로 모든 문서와 패키지 참조가 전환되었는지 확인한다.
2. 외부 소비자나 배포 스크립트가 `typescript/`를 직접 참조하지 않는지 확인한다.
3. 이상이 없으면 이 폴더를 제거한다.
